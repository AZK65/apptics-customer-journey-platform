Design Improvement — Dashboard

Apptics Customer Journey Platform · 2026-06-26

TL;DR: Re-skin the Dashboard as a proper analytics view — a borderless big-number KPI row, one hero area chart with two gradient series (leads vs won over time), and tidy breakdown lists with inline bar fills + icons (sources, stages, ad campaigns, services). Target aesthetic = the user's Framer Analytics page; charts from ui.shadcn.com/charts/area (Recharts).

Current State

The dashboard is functional but "cards-in-a-grid": four bordered KPI tiles, a horizontal-bar funnel, a sources list, an activity feed, and a "recently lost" list. It reads like a CRM table page, not an analytics dashboard. No time-series — you can't see momentum (are leads trending up?).

Target (provided by user)

Framer's Analytics page: a clean date-ranged header, a row of large borderless KPIs (Live Visitors, Unique Visitors, Pageviews, Bounce, Avg Session), a big smooth two-series area chart with purple+blue gradients, then 2×2 breakdown panels (Sources with favicons + counts, Pages, Geography, Devices) where each row has a subtle proportional bar fill behind it.

Improvement Ideas

1. Hero area chart — leads & won over time ⭐ highest impact

Add the one thing the current dashboard lacks: trend. A full-width gradient area chart (shadcn/Recharts) plotting daily New Leads and Won over the selected range, with the same purple/blue gradient fills as the Framer page. A date-range control in the header (Last 7/30/90 days) scopes it.

Why: KPIs answer "how many"; the area chart answers "which way is it going" — the single most useful addition for a sales dashboard, and the centerpiece of the target design.

2. Borderless big-number KPI row

Replace the four bordered tiles with a single borderless row of 5 large numbers (label small + muted above, big bold number below), divided by hairlines — exactly the Framer header. Metrics: Total Leads · Booked · Won · Lost · Win rate.

Why: Removes visual noise (8 card borders), lets the numbers breathe, and matches the target's clean header.

3. Breakdown lists with inline bar fills + icons

Turn the plain lists into Framer-style "Sources" panels: each row shows an icon + label on the left, a count on the right, and a subtle proportional bar fill behind the row. Use it for a 2×2 grid: Sources (where leads come from), Stages (pipeline distribution), Top Ad Campaigns (from FB attribution), Services requested.

Why: Same information density as today but far more scannable — the bar-behind-row pattern encodes proportion without a separate chart.

4. Quiet, analytics-grade surface

Tighten spacing, use muted hairline dividers instead of heavy card borders, and let the chart be the only saturated element (the gradients). Keep the app's light theme for consistency with the other pages, but adopt the analytics layout language.

What's Working

  • The funnel logic is solid — stage counts reconcile across views; keep the data, restyle the container.
  • Source attribution already exists and maps cleanly to a breakdown panel.
  • Recent activity is genuinely useful — keep it, just quieter.
  • Themed stage colors carry across the app — reuse them as the chart/series palette.
